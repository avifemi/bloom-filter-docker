# Docker

Простое веб-приложение на Flask с реализацией фильтра Блума, работающее в Docker-контейнере.

## Описание

Приложение предоставляет HTTP API для работы с фильтром Блума (Bloom Filter) — вероятностной структурой данных, предназначенной для проверки принадлежности элемента к множеству.

Фильтр может давать ложноположительные результаты, но не даёт ложноотрицательных при корректной реализации.

## Используемые технологии

- Python
- Flask
- Docker
- Docker Compose

## API

| Метод | Маршрут | Описание |
|---|---|---|
| GET | `/` | Проверка работоспособности сервера |
| POST | `/insert` | Добавление элемента в фильтр Блума |
| POST | `/search` | Проверка наличия элемента в фильтре |
